Privacy & what is stored

  

    
No ArchLab server. This is a static page. Your descriptions, diagrams and API key are never sent to us because there is nothing to send them to.

    
Sent over the network

    
    
      
  • Claude (optional, off by default): only if you switch to AI Mode with a key, the text and diagram you are working on go directly from your browser to api.anthropic.com. Offline Mode sends nothing.
    • 
      
  • Local AI (Ollama): if you choose it, requests go to localhost:11434 on your own computer only.
    • 
      
  • Nothing else. No visit counter, no analytics, no fonts or scripts from other sites. Once ArchLab has loaded it works with the network switched off.
    • 
    

    
Stored on this device

    
    
      
  • API key: this tab only (sessionStorage) — or localStorage if you tick Remember on this device. “Remove key” clears both.
    • 
      
  • Preferences (theme, mode, model, motion, minimap, recent templates), your library of saved diagrams and versions (IndexedDB), an offline cache of this app (service worker) and an autosave of your last diagram so a refresh doesn’t lose work. “Clear canvas” deletes the autosave.
    • 
    

    
Share links & embeds

    
The diagram is encoded in the URL after the #, which browsers do not send to servers. Anyone with the link can read the diagram, and apps you paste it into may log it.

    
Watermark

    
SVG, PNG, PDF/print, design-doc HTML, scaffolds, reports and project files all carry an ArchLab mark. It deters casual re-use; it cannot stop a screenshot.
